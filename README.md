# Javascript SMTP Mailer Applications

Welcome to the **Javascript SMTP Mailer Applications** repository! This project is a collection of applications built with JavaScript that demonstrate different scopes and use cases for sending emails via SMTP. 

Whether you are looking for a simple backend example or a fully-fledged premium UI for mass mailing, this repository has you covered.

## 📂 Projects Overview

### [1. Basic SMTP Server Connection](./1.%20Basic%20SMTP%20Server%20Connection)
This project serves as a practical foundation for setting up a basic **SMTP mailer connection with a Node.js web application** using **Express**.

**Key Features:**
- A simple Express server (`backend/server.js`).
- Environment variable configuration (`.env`).
- Basic HTML/CSS frontend for contact form submissions.

### [2. Mass E-Mail Sender Application](./2.%20Mass%20E-Mail%20Sender%20Application)
A beautiful, sleek, and simple UI for sending mass emails via your SMTP provider.

**Key Features:**
- **Premium UI**: Glassmorphism aesthetic with a dark mode base.
- **Multiple Senders**: Easily switch between predefined sender email addresses.
- **Mass Email Support**: Paste a list of emails (comma or newline separated) to send to multiple recipients at once.
- **Rich Text Support**: Enter HTML or plain text for your email body.

## 🚀 Getting Started

Each application resides in its own folder with specific setup instructions. To get started:

1. Clone this repository:
   ```bash
   git clone https://github.com/SerhatKumas/Javascript--SMTPMailerApplications.git
   cd Javascript--SMTPMailerApplications
   ```

2. Navigate to the project you want to explore:
   ```bash
   cd "1. Basic SMTP Server Connection"
   # or
   cd "2. Mass E-Mail Sender Application"
   ```

3. Follow the `README.md` instructions provided within that specific project folder to install dependencies and run the application.

## 🛠️ Technologies Used Across Projects

- **Frontend:** HTML, CSS, Vanilla JavaScript, Vite
- **Backend:** Node.js, Express.js
- **Email:** Nodemailer (SMTP configurations)
